## EqualEdu 
An educational web application developed to provide equal learning opportunities for all students. Our platform offers a simple, user-friendly, and responsive interface where students can easily access educational resources and improve their learning experience. The website is designed to make education more accessible, engaging, and convenient by using modern web technology.

## Features
- **PDF Studio:** Drag-drop any PDF -> auto scalable summary, key points, quiz & flashcards
- **7 Learning Modules:** Dashboard, Smart Lesson with TTS, Flashcards, Community Chat, Doubt Room, Study Planner, Pomodoro Timer
- **Real-time Social:** Course-wise community chat + Student-Teacher doubt room via Firebase
- **Full Accessibility:** 4 Languages, Dyslexic font, High Contrast, Reading Guide, Dark & Focus Mode
- **Works Everywhere:** Firebase auth + complete demo mode with LocalStorage

## How It Works 
1. User creates account / signs in / clicks Demo Mode
2. App goes to Dashboard -> shows XP, stats, timer
3. User selects course from sidebar -> all pages filter to that course
4. User uploads PDF in PDF Studio -> text extracted -> summary, key points, quiz, flashcards generated
5. User goes to Smart Lesson -> picks topic -> reads + listens via Read Aloud -> does Quick Check
6. User opens Flashcards -> flips, searches, shuffles to revise
7. User goes to Community -> chats with course peers, Doubt Room -> asks teacher
8. User adds tasks in Study Planner -> marks done -> stats update
9. User changes language/font/dark/focus mode from top bar
